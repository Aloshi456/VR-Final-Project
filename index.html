VR Heist Simulator

Objective: Crack the vault and collect the loot.

Tool: EMPTY HAND

Stage: LOCKED

Loot: 0 / 0

How to play:
1. Read the note on the table for the unlock order
2. Grab a tool from the table
3. Hold the tool close to its target until the bar fills
4. Repeat with the next tool in the sequence
5. When the vault opens, grab gold coins, drop in the bag

VR: Trigger to grab/release

Desktop: click canvas to capture mouse
WASD walk   Shift sprint   Space jump
Mouse - look   L-Click grab/release
U skip stage   R reset
B physics debug   Esc release mouse
